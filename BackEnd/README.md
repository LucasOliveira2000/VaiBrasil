# VaiBrasil

## Descrição

O VaiBrasil é um projeto de código aberto que visa fornecer uma plataforma para a comunidade brasileira
consultar rotinas, informações, gastos ou qualquer dado relacionado a cargos públicos, políticos, 
governamentais ou qualquer outro tipo de cargo público. 
O objetivo é promover a transparência e facilitar o acesso a informações relevantes para os cidadãos.
Projeto em desenvolvimento, ainda não possui funcionalidades implementadas.
Não há previsão de lançamento, mas o projeto está aberto para contribuições e sugestões da comunidade.
Sem fins lucrativos, o VaiBrasil é mantido por voluntários e entusiastas que desejam contribuir para a transparência e o acesso à informação no Brasil.

## Contribuição

Contribuições são bem-vindas! Se você deseja contribuir para o projeto, siga as etapas abaixo:
1. Fork este repositório.
2. Crie uma branch para sua feature ou correção de bug (`git checkout -b minha-feature`).
3. Faça suas alterações e commit (`git commit -m 'Adiciona minha feature'`).
4. Envie um pull request para este repositório.
